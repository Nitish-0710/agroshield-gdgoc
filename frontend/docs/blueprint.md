# **App Name**: AgroShield: Climate-Smart Farming

## Core Features:

- Simple Landing Page: Explains AgroShield with a clear tagline, concise description, and prominent CTA for advisory generation. Includes a language selector for English, Hindi and Marathi, expandable to accommodate additional languages in the future.
- Advisory Input Form: Collects location (city/village), crop type, and soil type through simple input fields and dropdowns.
- Climate Risk Assessment: Uses backend API data to assess climate risks (heat, drought, rainfall) for the specific location and crop, presented through a Low/Medium/High indicator.
- AI-Powered Advisory Tool: Generates actionable, crop-specific advice in plain language using generative AI.
- Clear Weather Summary: Displays weather information with icons, temperature, and rainfall chance.
- Alert System: Presents clear warning messages when high-risk conditions are detected, promoting timely action for farmers.
- Multilingual Support: Enables seamless switching between English, Hindi, and Marathi, reading text from translation JSON files, or i18n framework for easy addition of future languages, all without requiring a page reload.

## Style Guidelines:

- Primary color: Forest green (#388E3C) to represent agriculture and growth.
- Background color: Pale green (#E8F5E9), a light tint of the primary, for a soft and clean feel.
- Accent color: Earthy yellow (#FDD835) to draw attention to calls to action and important alerts.
- Body and headline font: 'PT Sans' for a clean, readable, modern feel, well-suited for long text.
- Use clear, simple icons to represent weather conditions, crop types, and risk levels, enhancing understanding for non-technical users.
- Implement a mobile-first, responsive layout that ensures readability and usability across devices, prioritizing ease of access for farmers in various environments.
- Subtle animations (e.g., fading transitions, button hovers) to provide gentle feedback and guide the user without being distracting.
